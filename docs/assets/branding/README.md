# Umicom C documentation artwork

These are byte-for-byte copies of the approved Umicom Framework resources/brand masters.
Use umicom-logo.svg on light guide surfaces, umicom-icon.svg for scalable identity
and umicom.ico where a Windows icon or browser favicon is supported.
Preserve their proportions, transparency and clear space.

The Framework master remains the source of truth. Review a master change and compare
bytes before updating these standalone documentation copies; do not redraw the identity.
The CMake documentation install includes this directory so relative guide links remain usable.

The Markdown viewer owns its fonts. Prefer the existing Umicom Segoe UI Variable Text /
Segoe UI roles and Cascadia Code / Consolas for code, with platform fallbacks.
No font files are included, downloaded or redistributed here.
